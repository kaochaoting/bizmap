# Kairos Engine 生態圈總 PRD

## 定位
Kairos Engine 是以 Kairos.Site 為核心的數位成交生態圈，目標是把中小企業的曝光、點擊、詢問、成交、評論與再曝光流程系統化。

## 生態圈節點
- Kairos.Site：核心主站，持續改版中
- AEO Scanner：附屬於 Kairos.Site 的 AEO 掃描工具
- BizMap：商家名錄聚合層
- K-Core：內部診斷核心，預計附掛於 BizMap
- KairosLink：外連服務官網
- QuickNotifys：商家檔案評論自動化產品
- MyCal：預約與付款承接系統
- 秒傳名片：LINE 電子名片

## 核心原則
1. 各站相互串連、相互導流
2. Kairos.Site 為主要商家資料入口
3. AEO 為附屬工具，不獨立成主產品線
4. BizMap 負責聚合曝光
5. K-Core 負責內部健檢、報告與報價
6. QuickNotifys / MyCal / 秒傳名片為後段承接與互動節點

## MVP 優先順序
1. K-Core MVP
2. Kairos.Site 主站與後台
3. AEO Scanner 與 BizMap 基本同步
4. QuickNotifys 正式 PRD 與整合
5. MyCal / 秒傳名片串接
