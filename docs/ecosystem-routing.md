# 生態圈串連與導流架構

## 原則
Kairos Engine 各網站必須相互串連、相互導流，不可形成孤島。

## 主要路徑
- Kairos.Site → AEO Scanner / BizMap / QuickNotifys / MyCal / 秒傳名片 / K-Core
- BizMap → Kairos.Site / MyCal / 秒傳名片 / K-Core
- K-Core → Kairos.Site / BizMap / QuickNotifys / MyCal / 秒傳名片 / KairosLink 官網
- QuickNotifys → Kairos.Site / BizMap / MyCal / K-Core
- MyCal → Kairos.Site / 秒傳名片 / BizMap
- KairosLink 官網 → K-Core / Kairos.Site / BizMap

## 一致性欄位
- business_id
- 商家名稱
- 類別
- 地區
- 主頁連結
- 預約連結
- 名片連結
- 模組啟用狀態
